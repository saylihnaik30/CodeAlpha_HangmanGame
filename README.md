# CodeAlpha Hangman Game

## Project Overview
This is a simple text-based Hangman game developed using Python as part of the CodeAlpha Python Programming Internship.

## Features
- Randomly selects a word from a list of five predefined words.
- Allows the player to guess one letter at a time.
- Limits incorrect guesses to six.
- Displays correct guesses and the remaining attempts.
- Shows a winning or game-over message.

## Technologies Used
- Python
- random module
- Lists and strings
- While loops and for loops
- Conditional statements
- User input and output

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run the following command:


python hangman.py
